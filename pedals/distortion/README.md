# Distortion Pedal (Flashover)

The first GreywireStudio pedal: an analog distortion / overdrive in the Linework series, with gain, tone and level controls. It works on its own or controlled by the Switchyard control pedal. See `Flashover Product Document.docx`.

The design files still use the internal name GS1.

## Folders

- `kicad/` - KiCad project (schematic and PCB layout)
- `sim/` - LTspice simulations of the circuit
