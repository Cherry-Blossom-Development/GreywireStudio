# Controller Pedal (Switchyard)

The Linework series control pedal. A phone (iPhone or Android) plugs into it over USB-C, and two footswitches step up and down through pre-configured settings for all connected pedals. See `Switchyard Product Document.docx`.

## Status

Concept - main features decided (October 2026), no circuit yet. Next: breadboard prototype on a Raspberry Pi Pico, firmware, and a Web MIDI test tool.
