# Boost Pedal (Tap Changer)

A clean boost in the Linework series, with one Boost knob and a footswitch. It works on its own or controlled by the Switchyard control pedal. See `Tap Changer Product Document.docx`. Breadboard parts: `Tap Changer Breadboard Tayda Order.docx`. Build steps: `TAP_CHANGER_BREADBOARD_STAGE1_BUILD.md`, then stage 2 (the digital pot, Pico and endless knob, borrowing Flashover's stage 2 boards): `TAP_CHANGER_BREADBOARD_STAGE2.md`. Layout diagram: `TAP_CHANGER_BREADBOARD_STAGE1_LAYOUT.html`. Tick-off checklist (Claude Doc): https://claude.ai/artifact/KsizN1bWHvuWPb2jqyFpgn.

## Folders

- `sim/` - LTspice simulations of the circuit
- `kicad/` - schematics for both boards
- `firmware/` - firmware for the RP2040 (started Nov 5, 2026; not yet run on hardware)
