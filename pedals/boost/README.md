# Boost Pedal (Tap Changer)

A clean boost in the Linework series, with one Boost knob and a footswitch. It works on its own or controlled by the Switchyard control pedal. See `Tap Changer Product Document.docx`.

## Folders

- `sim/` - LTspice simulations of the circuit

## Status

Design - audio circuit simulated, nothing built yet. There is no KiCad project yet.
