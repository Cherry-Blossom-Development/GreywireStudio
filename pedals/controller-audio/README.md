# Controller Pedal with Audio (Switchyard Audio)

A second version of the Switchyard control pedal that also carries the guitar signal and adds digital effects (delay, reverb and others) after the analog Linework pedals. It keeps every Switchyard control feature. The control-only Switchyard in `pedals/controller/` is kept as a separate candidate; which version(s) we build will be decided later, mostly on cost.

## Status

Planning (October 2026). See `SWITCHYARD_AUDIO_PLAN.md`. Decided: the effects run on a processor in the pedal, not in the phone app.
